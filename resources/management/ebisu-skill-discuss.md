# 讨论 Ebisu 经验

用户调用时传入 `id[]`（一条或多条经验 ID）以及意见，例如：
`ebisu-skill-discuss ["UUID-1","UUID-2"] 请解释这两条经验；如果第二条与当前实践冲突，修正它。`

先运行入口提供的客户端 `protocol`，再执行 `experiences --ids '["UUID-1","UUID-2"]'`。不得猜测 ID、正文、归属或修订号。不存在的 ID 应明确报告。

按用户意见解释、修改、新增或删除指定经验。仅解释时保持只读；没有明确要变更的内容时，不为了讨论而改写。

- 修改：experience-update，提交原 ID、当前 revision、新正文及验证依据。ID 保持不变。
- 新增：experience-add，保留正确 skillId 和可选 folderId，并提供实际 evidence。
- 删除：experience-delete，提交 ID 与当前 revision。
- 409 表示并发修改；重新读取、重新判断后才能再次提交，不盲目覆盖。

初始上下文和脚本不属于经验，不得借讨论接口改写。不要将凭据写入经验。项目经验仅归属对应技能和项目；技能经验供所有项目、终端和模型共享。

结束时列出实际变更的 ID、内容要点及仍需验证的问题，不自动向其他终端或聊天发消息。
